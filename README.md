## 当前方案

- ShellCrash 1.9.4release；Mihomo Meta v1.19.28，ARMv7 UPX 版本。
- 原厂固件不改刷 OpenWrt；持久化目录为 `/data/ShellCrash`。
- TCP / UDP 透明代理用 TPROXY；DNS 用 fake-IP，国内和游戏域名有例外。
- 保留香港、日本、美国共 54 个节点；自动测速只用三条代表节点。
- `AI 美国` 单独选择美国节点；普通国外流量使用 `代理` 组。
- 一次性订阅已缓存为文件，不进行重复 HTTP 订阅更新。
- 本实例 `GOMEMLIMIT=12MiB`、`GOGC=30`；它们是调优参数，RSS 实测仍接近 49 MiB。

家用客户端的请求需要经过这台路由器。连到上级路由器的 Wi-Fi、开启手机蜂窝回退、客户端另开 VPN 或使用其他 DNS，都会让检查结果与预期不同。

## 当前验证边界

已验证 SSH、面板认证、TCP 透明分流、AI 规则与美国出口、DNS 例外、自启动和一次正常重启恢复。永劫无间相关域名的直连规则已加载；主人随后确认游戏正常，原先的问题是没有登录，要求停止继续排查。没有做长期满载稳定性测试，也没有采集完整游戏对局遥测。
